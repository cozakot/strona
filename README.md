# Kostka i Kawa – projekt RWD

Serwis kawiarni planszówkowej w Krakowie. Główny cel strony: **rezerwacja stolika**.

- Strona: https://TWOJLOGIN.github.io/kostka-i-kawa/
- Grupa docelowa: studenci i młodzi dorośli (18–35 lat) z Krakowa, szukający miejsca na spotkanie przy grach.
- Technologia: HTML + Bootstrap 5.3.3 (CDN) + jeden plik `style.css`.

## Marka
| Rola | Kolor | Kontrast |
|---|---|---|
| Wiodący | `#1f4e5f` | 9.08:1 z białym |
| Pomocniczy | `#f2e8da` | tło sekcji, tekst `#222222` na nim 13.13:1 |
| CTA | `#b3401f` | 5.72:1 z białym tekstem |
| Tekst | `#222222` | 15.91:1 na białym |

Kroje: **Bitter** (nagłówki), **Source Sans 3** (tekst).
